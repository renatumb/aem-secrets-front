# Aem Blog - frontend

A modern Angular-based blog application with a public reader side and a secure author dashboard. It uses feature modules, standalone components, and lazy loading for clean structure and performance. Readers can browse posts, categories, and submit comments, while authors can manage content through an authenticated dashboard.

See it live at https://aemsecrets.com/

## Development server

Run `ng serve` for a dev server. Navigate to `http://localhost:4200/`. The application will automatically reload if you change any of the source files.
